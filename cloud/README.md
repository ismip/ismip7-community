# Cloud platforms

Contributions about the platforms themselves: reading ISMIP7 data from
source.coop, setting up an environment on CryoCloud. Each folder here is
one contribution, with its own README.

A tool for one ice sheet goes in [AIS/](../AIS/) or [GrIS/](../GrIS/),
even if it runs in the cloud.
[CONTRIBUTING.md](../CONTRIBUTING.md#where-it-goes) says where things go.
